## 🧩 About

**Squad Tool** is a comprehensive overlay and utility suite for Squad featuring tactical overlay, server browser, performance monitor, config editor, and training mode.

Based on popular tools like **SquadJS**, **Squad Overlay**, and **Squad Calc**.

---

## ✨ Features

### 🎮 Core Tools
- Tactical Overlay — display real-time tactical information on screen
- Server Browser — quick join and filter community servers
- Performance Monitor — track FPS, ping, and system stats
- Config Editor — adjust game settings without restarting
- Training Mode — practice shooting and movement in a controlled environment

### 🎨 Interface & Customization
- Custom HUD — personalize your heads-up display
- Theme Support — light and dark modes
- Hotkey Binding — assign custom keys for all features

### 🏋️ Practice & Training
- Aim Trainer — improve accuracy with customizable drills
- Movement Trainer — master vaulting, climbing, and sprinting
- Recoil Control — practice weapon handling
